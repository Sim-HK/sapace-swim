# Space Swim

손 제스처(웹캠)나 마우스·터치로 성운을 헤엄치고, 별을 잡아 돌려보고, 그 행성의 하늘을 나는 웹 게임.

```bash
npm install
npm run dev   # http://localhost:5180
```

## 모드
- **우주 유영**: 성운과 성단 사이를 헤엄친다. 행성 16개(바다·암석·가스·얼음·용암·수정·항성)
- **행성 관측**: 행성을 잡으면 가까이 다가가 돌려보고 확대할 수 있다
- **대기권 비행**: 행성마다 다른 지형, 하늘, 구름, 바다(용암·플라스마) 위를 난다

## 손 제스처
| 제스처 | 우주 | 관측 | 비행 |
|---|---|---|---|
| ✋ 손바닥 | 헤엄 + 손 위치로 방향 | – | 가속 + 조종 |
| ☝️ 검지 | 천천히 헤엄 | – | 순항 + 조종 |
| 🤏 집기 | 별 잡기 / 끌어서 둘러보기 | 끌어서 회전 | – |
| ✌️ 유지 | – | 하늘 비행 | – |
| ✊ 주먹 | 멈춤 | 1초 유지 → 우주로 | 1초 유지 → 궤도로 |
| 🙌 두 손 | 앞뒤로 | 확대·축소 | – |

키보드: W/S 헤엄, A/D·방향키 회전, Shift 가속, F 비행, Esc 뒤로, H 도움말.

## 구조
- `src/space.js` 성운 하늘, 별·성단, 먼지, 행성 배치
- `src/planets.js` 행성 데이터와 절차적 행성 셰이더
- `src/flight.js` 무한 지형 비행 장면
- `src/hands.js` MediaPipe 손 인식과 제스처 분류
- `src/input.js` 마우스·터치·키보드·손 입력 통합
- `src/main.js` 모드 전환과 메인 루프
